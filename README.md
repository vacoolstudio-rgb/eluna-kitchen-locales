# eluna-kitchen-locales

Языковые пакеты для [Eluna Kitchen](https://github.com/vacoolstudio-rgb/eluna-kitchen).

## Зачем это отдельно от приложения

В приложении остаётся английский — язык, на котором пишутся сами строки, и
запасной для всех остальных. Шестьдесят языков внутри сборки — это десятки
мегабайт, из которых человеку нужен ровно один; здесь он скачивает свой.

Второе: перевод правится чаще, чем выходит приложение. Исправленная опечатка
доезжает до людей коммитом сюда, а не выпуском в магазине.

Тот же приём, что у Eluna Cycle
([eluna-kb-locales](https://github.com/vacoolstudio-rgb/eluna-kb-locales)).

## Как устроено

`manifest.json` — версия сборки и по строке на язык: файл, sha256, размер и
число переведённых ключей. Приложение читает манифест, качает выбранный язык и
**проверяет sha256**; не сошёлся — пакет выброшен, интерфейс остаётся на
прежнем языке.

```json
{
  "version": "2026-08-26",
  "defaultLocale": "en",
  "locales": {
    "uk": { "file": "lang_uk.json", "sha256": "…", "bytes": 61000, "items": 742 }
  }
}
```

Сам пакет — плоская карта «ключ → строка», ровно те ключи, что в ARB
приложения:

```json
{ "diaryAddTitle": "Записати з'їдене", "weightAdd": "Записати вагу" }
```

Собирается инструментом `tool/build_locale_packs.py` из репозитория приложения.

## Что сюда не приходит

Ничего. Это статика в одну сторону: два GET-запроса без единой строки о
человеке.
